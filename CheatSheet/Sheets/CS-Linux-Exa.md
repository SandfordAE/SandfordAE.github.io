# Linux & Exa (Modern `ls`) Cheatsheet

## Directory Listing & Trees
- **List Files with Details** (`exa -la --git`): `-l` (long format), `-a` (all hidden files), `--git` shows Git status per file.
- **Display Tree View** (`exa --tree --level=2`): `--tree` displays directory contents as a tree structure up to a specified `--level`.
- **List Sorted by Size** (`exa -l --sort=size`): Lists files in long format sorted by file size.
