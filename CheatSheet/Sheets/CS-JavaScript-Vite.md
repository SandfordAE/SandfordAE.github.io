# JavaScript & Vite Cheatsheet

## Vite CLI Operations
- **Scaffold Vite Project** (`npm create vite@latest app-name -- --template react-ts`): Initializes a lightning-fast Vite project with your chosen framework template.
- **Install Dependencies** (`npm install`): Installs all dependencies specified in package.json.
- **Start Dev Server** (`npm run dev`): Launches Vite's native ESM dev server with instant hot module replacement (HMR).
- **Production Build** (`npm run build`): Bundles optimized static assets into `dist/` using Rollup under the hood.
