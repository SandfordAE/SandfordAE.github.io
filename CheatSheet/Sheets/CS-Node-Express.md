# Node.js & Express Cheatsheet

## Server Setup & Routing
- **Initialize Node Project** (`npm init -y`): Creates a default `package.json` file without interactive prompts.
- **Install Express** (`npm install express`): Installs the Express minimal and flexible Node.js web application framework.
- **Express Basic Server Template** (`const express = require('express'); const app = express(); app.listen(3000);`): Minimal boilerplate to spin up an HTTP server on port 3000.
