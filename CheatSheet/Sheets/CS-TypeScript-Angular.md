# TypeScript & Angular Cheatsheet

## Angular CLI Operations
- **Create New Angular Workspace** (`npx @angular/cli new project_name`): Scaffolds a modern Angular workspace with strict type-checking and routing.
- **Generate Component** (`ng g c component_name`): Automatically generates a component folder with TS, HTML, CSS, and spec test files.
- **Generate Service** (`ng g s service_name`): Generates an injectable service for data fetching and business logic.
- **Serve Development App** (`ng serve --open`): Compiles the application in-memory and opens it automatically in the default browser.
- **Build for Production** (`ng build --configuration production`): Bundles and optimizes application assets into `dist/` for production deployment.
