# Full Stack Web & Node / Python Stacks

## Node.js & Vite / React
- **Create Vite Project:** `npm create vite@latest app-name -- --template react-ts`
- **Install Dependencies:** `npm install`
- **Run Dev Server:** `npm run dev`
- **Build for Production:** `npm run build`

## Python & FastAPI / Uvicorn
- **Create Virtual Environment:** `python3 -m venv venv`
- **Activate Virtual Environment:** `source venv/bin/activate`
- **Install FastAPI & Uvicorn:** `pip install fastapi uvicorn`
- **Run Development Server:** `uvicorn main:app --reload --port 8000`

## Git & Version Control Quick Reference
- **Check Status & Diffs:** `git status && git diff`
- **Stage & Commit:** `git add . && git commit -m "feat: description"`
- **View Commit History:** `git log --oneline -n 10`
