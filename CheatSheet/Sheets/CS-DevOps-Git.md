# DevOps & Git Cheatsheet

## Repository Operations
- **Check Status & Diffs** (`git status && git diff`): Displays modified files and unstaged changes in the working tree.
- **Stage & Commit** (`git add . && git commit -m "feat: message"`): Stages all changes and records them in the local repository with a commit message.
- **View Commit History** (`git log --oneline --graph -n 20`): Displays a compact graphical commit history tree.
- **Discard Unstaged Changes** (`git restore .`): Discards all working directory changes in tracked files.
